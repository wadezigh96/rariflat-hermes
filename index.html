HERMES AGENT · COMMUNITY PLUGIN

Meet Rariflat.

A local-first tool reliability and routing plugin designed to make Hermes Agent workflows more observable, informed, and controlled.

GitHub Repository Catalog Pull Request Demo Video

What it does

Tool reliability tracking

Tracks local tool-use outcomes to help make tool reliability more visible.

Task-aware routing suggestions

Suggests observed tools for a task using locally collected statistics.

Opt-in execution guard

The guard is off by default and blocks only tools explicitly listed by the user.

Privacy by design

Local-only statistics are stored under $HERMES_HOME/plugin-data/rariflat/. No network calls, credentials, or subprocesses are required by the plugin.
