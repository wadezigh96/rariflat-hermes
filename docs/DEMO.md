# Demo Video Script (< 90 seconds)

## Voiceover + Visuals

**0:00–0:08**  
Visual: Desktop pane open, empty state.  
"Most agent tools are invisible. Rariflat makes them alive."

**0:08–0:25**  
Visual: Ask Hermes to search the web. Owl appears in the pane + terminal reaction.  
"Every tool call wakes a character. Web search brings the Owl."

**0:25–0:40**  
Visual: Ask it to run a terminal command. Hephaestus appears.  
"Terminal work forges with Hephaestus."

**0:40–0:55**  
Visual: Trigger something that fails or is restrained. Cerberus appears.  
"When something goes wrong or gets blocked, Cerberus guards the gate."

**0:55–1:10**  
Visual: Run `/rariflat` or call `rariflat_route`. Show the ranking.  
"It also learns. Skills are ranked by rarity and restraint, so the agent can route to the best one."

**1:10–1:20**  
Visual: Character succeeds again. End on the pane.  
"Rariflat — characters that live with your agent. Built for the Hermes Plugin Hackathon."
